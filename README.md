# Khun Sophavisnuka - Portfolio

Personal portfolio of **Khun Sophavisnuka**, a full stack developer and final-year Software Engineering student at CADT (Cambodia Academy of Digital Technology) in Phnom Penh, Cambodia.

The site showcases full stack projects, graphic design posters, work experience, and achievements, built with [Next.js](https://nextjs.org), TypeScript, and Tailwind CSS.

**Live site:** [sophavisnuka.vercel.app](https://sophavisnuka.vercel.app)

## Sections

- **Home** - Introduction and tech stack (React, Next.js, Node.js, Laravel, Flutter, and more)
- **Projects** - Full stack and mobile applications
- **Posters** - Graphic design and poster work
- **About** - Background and education
- **Work Experience** - Professional experience
- **Achievements** - Certifications and awards
- **Contact** - Get in touch

## Tech Stack

- [Next.js](https://nextjs.org) (App Router)
- TypeScript
- Tailwind CSS
- [next-themes](https://github.com/pacocoursey/next-themes) for light/dark mode

## Getting Started

Install dependencies and run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Deployment

Deployed on [Vercel](https://vercel.com).
